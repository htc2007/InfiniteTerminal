# 无限终端 Infinite Terminal

一个 tModLoader 模组。新增两件物品，让你随时随地远程访问世界里已绑定的箱子，并在背包中直接使用箱子里的材料制作物品。

## 功能与物品



| 物品      | 作用                                               |
| ------- | ------------------------------------------------ |
| 无线终端接收器 | 手持时左键点击附近的箱子进行绑定；再次点击已绑定的箱子可解绑。可绑定多个箱子，无数量上限。    |
| 无线终端    | 使用后打开聚合界面，远程访问所有绑定箱子；它在背包中时，配方系统可直接使用绑定箱子内的全部材料。 |



* 绑定的箱子被拆除后，界面中该分组会标记为**失效**（红色标题、槽位灰色禁用）；重新放置箱子后需要重新绑定。

* 聚合界面只做统一显示与存取，**不会在不同箱子之间移动物品归属**。

* **开局即送**：角色首次进入世界时自动获得无线终端与无线终端接收器各一个；该发放记录随玩家存档保存，整套只发一次。若把它们丢弃或卖掉，需要按下方配方自行制作。

## 安装要求



* 正版 Terraria，以及 Steam 上的免费应用 **tModLoader**（AppID 1281930）。

* 本模组面向 tModLoader 2026.08（对应 Terraria 1.4.4.9）构建，首版仅支持单人 / 单机。

## 使用说明



1. 角色首次进入世界时，背包中已自动获得**无线终端接收器**与**无线终端**各一个，无需先合成。

2. 手持接收器，左键点击附近的箱子完成绑定；可重复操作绑定多个箱子。

3. 若开局物品丢失，可按下方「合成配方」在工作台自行制作。

4. 手持无线终端使用，打开聚合界面：

* **全部取出**：把所有绑定箱子里的物品移入玩家主库存（50 个槽位，不写入钱币栏/弹药栏），背包放不下的会留在箱子里，不会丢失。

* **全部存入**：把背包中未收藏（favorite）的物品存入箱子；钱币栏与弹药栏不动。

* **快速堆叠**：只存入箱子里已经存在同类的物品，其余不动。

* **整理**：对每个绑定箱子分别排序（钱币 / 装备 / 武器 / 消耗品 / 放置物 / 其他，再按类型、前缀、堆叠数）。

1. 无线终端放在背包中时，打开制作列表即可看到绑定箱子内材料支持的配方；制作时材料会直接从对应箱子中扣除。

## 合成配方

两件物品配方独立，均在**工作台**合成，其中「任意金属锭」指铁锭或铅锭（二者等价，可混用）。

| 成品 | 材料 | 合成站 |
| --- | --- | --- |
| 无线终端 | 10 个木材 + 2 个任意金属锭（铁锭/铅锭） | 工作台 |
| 无线终端接收器 | 10 个木材 + 2 个任意金属锭（铁锭/铅锭） | 工作台 |

## 从源码构建

本机没有独立 .NET SDK，使用 tModLoader 自带的运行时即可，在 tModLoader 安装目录下执行：



```
& ".\dotnet\dotnet.exe" ".\tModLoader.dll" -build "C:\Users\user\Documents\My Games\Terraria\tModLoader\ModSources\InfiniteTerminal"
```

构建成功后会生成 `InfiniteTerminal.tmod` 并放入 tModLoader 的 `Mods` 目录。也可以在游戏内 **Workshop → Mod Sources** 菜单点击 **Build + Reload** 构建。

## 发布到 Steam 创意工坊

### 发布前的硬性校验（tModLoader 会自动检查）



* 必须是 **Release 构建**，不能是 Debug 构建。

* 必须包含 `description.txt`，且不能是默认模板、字母数字字符数不少于 50。

* `description_workshop.txt` 若存在，不能是默认模板，也不能包含 Steam 排版指南链接。

* `icon.png` 不能是默认图标。本模组均已满足这些条件。

### 首次发布



1. 启动 tModLoader，主菜单进入 **Workshop（创意工坊）**。

2. 打开 **Mod Sources（开发模组）**，在列表中找到 **InfiniteTerminal**。

3. 点击该模组对应的 **Publish（发布）** 按钮。

4. 在发布设置中填写 / 确认：

* 工坊标签（tags）、可见性（公开 / 好友 / 隐藏）；

* 预览图自动使用 `icon.png`；

* 工坊描述自动使用 `description_workshop.txt`。

1. 确认后等待 Steam 上传，完成后会返回工坊页面链接与工坊物品 ID。

### 后续更新



1. 修改代码或资源后，先把 `build.txt` 中的 `version` 递增（例如 `0.1.0` → `0.1.1`）。

2. 重新构建并确认 0 错误。

3. 在 **Mod Sources** 中再次点击 **Publish**，此时为更新已有工坊物品，填写本次变更说明（changelog）后提交。

4. 已订阅玩家会通过 Steam 自动收到更新；版本号相同不会被识别为新版本，因此每次发布都必须递增版本号。

## 已知限制



* 首版仅保证单人 / 单机可用，未实现多人联机下的网络同步。

* 聚合界面不跨箱子自动调拨物品；物品始终保留在原箱子内。

* 箱子被挖掉后绑定记录保留但标记失效，需要重新绑定。
